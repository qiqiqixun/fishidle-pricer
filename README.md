# FishIdle 日均收益定价器

给 [FishIdle](https://fishidle.com) 用的挂机定价小工具：填一个目标日收益（比如 `10K`），直接算出每条配方、每个采集区域的 **单件耗时 / 日产量 / 达标单价**。

- 全量数据：617 条配方、28 个采集区域（采矿 / 伐木 / 采集 / 钓鱼），取自游戏公开数据接口
- 前置工序递归计算：做铁镐会把枫木棍、铁锭、铜镐的工时全部摊进单件成本
- 材料两种口径：全自产（工时全算）/ 材料外购（按市价扣成本），并可单独把某一种材料设为自产
- 加速按类别单独设置，换算公式为「有效时间 = 基础时间 ÷ (1 + 加速%)」，逐层生效
- 收益输入支持 `10K` / `1.5M` / `3万`，结果同样以 K/M/B 显示
- 界面仿游戏卡片列表：左栏采集/制造、中栏类别、顶部搜索 + T1–T8 筛选，点卡片出详情
- 手机可用：窄屏自动切换为全屏单列布局

## 两种用法

### 1. 油猴脚本（推荐，游戏页内浮层）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 从下面的链接安装脚本（Tampermonkey 会自动弹出安装页）

```
https://raw.githubusercontent.com/<用户名>/<仓库名>/main/fishidle-pricer.user.js
```

3. 打开 `https://fishidle.com/game/...`，页面上会出现一个小「价」图标，点开即用

浮层支持拖动、右下角拖拽缩放、按钮收起；位置、尺寸、参数、材料价都会记在 localStorage。

### 2. 网页版（不需要任何插件）

直接打开 GitHub Pages 地址即可：

```
https://<用户名>.github.io/<仓库名>/
```

也可以把 `index.html` 下载到本地，双击用浏览器打开，完全离线可用。

## 口径与边界

- **单件满产口径**：一次产出算一件的单件价，产出 ×2 的按两件摊工时，给出的是「一件卖多少钱」
- **纯本地计算**：不登录、不自动操作、不向游戏发请求，不会影响你的角色
- **155 条配方无法估算**：材料来自战斗掉落（兔皮、狼皮、星核碎片等），没有稳定工时来源，界面标「缺材料来源」，不给估算值
- 数据版本：`ce8e1be2a1298e72`（items `92cc4252eb444e0a`），游戏更新后配方变动需同步
